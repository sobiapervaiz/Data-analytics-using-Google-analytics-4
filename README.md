Google Analytics 4 has emerged as the largest and most comprehensive platform used for the data analysis of the properties like websites or apps to help business understand the data and make data-driven decisions. This massive platform can be used to create Overview Reports for the summary of the data about a certain topic with the help of summary cards. Detail Reports can be used for the in-depth information of the data about an area of interest by using two charts and a table. Audience reports can help identifying the most profitable and engaged users of the website. Similarly, Path Exploration reports provide valuable details about the customer journey on the website, leading to a deeper understanding of how users are interacting with the property.  This project uses Henry’ shoe business and his E-Commerce website as a case study to explain the Google Analytics platform. Different reports are created to explain the benefits of using these reports to improve the performance of the business. Also, screenshots are used to visually understand the process.
