A.	Project Description (4-5 lines): 

Henry is using an e-commerce website for his shoe business. He now wants to track user journeys and activities through Google Analytics 4. As the next step, he created a GA4 account for his website.


Task 1:  How will Henry connect his website to Google Analytics?  (5 Marks)

Task 2: How will Henry create an overview report in GA4? (9 Marks)

Task 3: Henry wants to create a custom report on the GA4 dashboard. How is he going to do that? (10 Marks)

Task 4: Henry wants to retarget those who have already added products to their cart but haven't purchased them yet. How is he going to do that? (4 Marks)

Task 5: Henry wants to evaluate the customer purchase journey. How is he going to view the purchase journey report, and what funnel steps should be included? (7 Marks)
